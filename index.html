Descarregue a app para Android.

Descarregar a versão mais recente (.apk)

No telemóvel, ao abrir este link, o Android pode pedir para permitir a instalação de "fontes desconhecidas" — é normal para apps distribuídas fora da Play Store.

Como instalar, passo a passo
  1. Toque em "Descarregar a versão mais recente" acima e abra o ficheiro .apk transferido (normalmente a partir da notificação de download ou da pasta Downloads).
  2. Se pedir para permitir instalar "fontes desconhecidas" para o navegador ou gestor de ficheiros que usou, toque em Definições e ative essa opção só para essa app.
  3. Pode aparecer um aviso "App bloqueada para proteger o dispositivo" (Google Play Protect). Toque em "Mais detalhes" e depois em "Instalar mesmo assim". É normal — significa só que o Google ainda não analisou esta versão em concreto, não que haja algum problema com o ficheiro.
  4. Pode ainda perguntar se quer "Enviar esta app para a Google para revisão". Pode escolher "Não enviar" — não afeta a instalação.
  5. A instalação prossegue normalmente a partir daqui.

Se o Android recusar instalar "por cima" de uma versão já existente e pedir para desinstalar primeiro: isso apaga o código interno do equipamento, por isso vai ser preciso colar uma licença nova em Ajustes → Licença depois de reinstalar.

Se reinstalar e continuar a ver a versão antiga: apague o .apk anterior da pasta Downloads antes de descarregar outra vez. O Android costuma reaproveitar o ficheiro já guardado em vez de ir buscar o novo.
